# Roadmap

1. District Zero foundation: movement, camera, vehicles, combat, health, HUD,
   proportioned district and integration validation.
2. Playtest and tune controller/camera/driving on real hardware; improve feedback,
   character animation, collision response and vehicle silhouettes.
3. Add navigation-aware enemy movement and an authored short encounter/mission.
4. Replace selected procedural architecture with original modular authored assets,
   add spatial engine audio, pedestrians and traffic only after the core is stable.
5. Consider district streaming and broader city design after vertical-slice approval.
